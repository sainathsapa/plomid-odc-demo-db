# MVCC and filtering — deep dive

## MVCC working (`crates/mvcc`)

`RowVersion{creator, commit_ts?, state, payload?, prev}` newest-first chains in `BTreeMap<key, Vec<RowVersion>>`.

```mermaid
flowchart TB
    W["write: buffer + WAL Data"] --> C["commit: ts + fsync + apply + install"]
    C --> V["chain head: Live ts=N"]
    V --> R["read: snapshot{watermark, active}"]
    R --> K{"visible?"}
    K -->|"own creator"| YES["yes"]
    K -->|"uncommitted/no-ts"| NO["no"]
    K -->|"active creator or ts > watermark"| NO
    K -->|"else"| YES
    NO --> PREV["walk prev"]
```

`visible_or_unknown`: `None` → storage fallback (pre-MVCC bootstrap `TxnId(0),ts0`), `Some(None)` → deleted/invisible, `Some(Some)` → payload. `gc(horizon=min(active) else last)` keeps uncommitted + `ts>horizon` + newest `ts<=horizon` floor per chain. Engine `SharedVersionStore + versions_complete` (mount `bootstrap_versions`, maintained by `install_committed`); reads page `SCAN_CHUNK_ROWS=1024` under fixed snapshot.

## Filtering pipeline (`crates/filters`, `columnar/pruning`)

```mermaid
flowchart LR
    SQL["WHERE predicate"] --> Low["lower_sql_expression → PrunePredicate"]
    Low --> ZM["ZoneMap{min,max,null}"]
    ZM --> BRIN["BRIN tiling"]
    BRIN --> XOR["XorFilter 3-hash 8-bit, FPR 0.83%"]
    XOR --> EX["exact evaluation"]
    RO --> EX["exact recheck"]
```

Rule: **PRUNE only if metadata proves no match; missing/uncertain/malformed → KEEP**. XOR never authoritative (`true` → exact evaluation). Time predicates are normalized before lowering.
